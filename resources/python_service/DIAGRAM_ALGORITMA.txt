== PERBANDINGAN: ALGORITMA LAMA vs BARU ==

┌─────────────────────────────────────────────────────────────────┐
│                    ALGORITMA LAMA (Hardcoded)                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1. DETEKSI KEYWORD LANGSUNG                                     │
│     if "samsat" in text → check lokasi → SAMSAT_BANJARBARU      │
│     if "ktp" in text → langsung DUKCAPIL                         │
│     if "bpjs" in text → langsung BPJS                           │
│                                                                   │
│  2. LOKASI HANYA UNTUK SAMSAT                                    │
│     if "banjarbaru" in text → SAMSAT_BANJARBARU                 │
│     else → BUTUH_LOKASI                                          │
│                                                                   │
│  3. JENIS LAYANAN TERPISAH                                       │
│     detect_jenis_layanan() → search ["lansia", "darurat", dll]  │
│                                                                   │
│  KELEMAHAN:                                                       │
│  ❌ Hardcoded, perlu edit code untuk update                      │
│  ❌ Tidak scalable untuk kategori baru                          │
│  ❌ Keyword limited, tidak bisa dinamis                         │
│  ❌ Tidak cocok untuk multi-institusi                           │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                    ALGORITMA BARU (Database)                    │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1. LOAD DATA DARI DATABASE                                      │
│     startup: load_database_config()                              │
│     ├─ SELECT * FROM loket                                       │
│     └─ SELECT * FROM algoritma                                   │
│                                                                   │
│  2. SEARCH ALGORITMA DI DATABASE                                 │
│     search_algorithm_in_db(text)                                 │
│     └─ return {loket_id, tipe_layanan, lokasi}                  │
│                                                                   │
│  3. LOGIKA ROUTING BERDASARKAN COLUMN 'LOKASI'                   │
│     if algoritma.lokasi == 'YA' (SAMSAT)                        │
│        ├─ if text contains lokasi → loket tertentu               │
│        └─ else → BUTUH_LOKASI                                    │
│     else (BPJS, DUKCAPIL, DISNAKER)                             │
│        └─ langsung arahkan ke loket                              │
│                                                                   │
│  KEUNTUNGAN:                                                      │
│  ✅ Dynamic, bisa update database langsung                       │
│  ✅ Scalable, tambah kategori di DB tanpa code                  │
│  ✅ Flexible, keyword bisa unlimited                            │
│  ✅ Multi-loket, support semua jenis institusi                  │
│  ✅ Admin-friendly, UI untuk manage algoritma                    │
│  ✅ Maintainable, pisah data dari logic                         │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
