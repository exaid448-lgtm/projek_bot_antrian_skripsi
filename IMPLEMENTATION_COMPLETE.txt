  📊 STRUKTUR DATABASE
================================================================================

Tabel: antrian
├── id_antrian (PRIMARY KEY)
├── id_konsul (FOREIGN KEY → konsul)
├── id_loket (FOREIGN KEY → loket)
├── nomor_antrian (AUTO: 001, 002, dst)
├── waktu_diberikan (AUTO: saat submit)
├── antrian_mulai (NULL → admin klik Mulai)
├── antrian_selesai (NULL → admin klik Selesai)
├── jenis_antrian (NULL → siap feature nanti)
└── timestamps (created_at, updated_at)
