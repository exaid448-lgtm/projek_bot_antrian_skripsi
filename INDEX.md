## 🚀 MULAI DALAM 3 LANGKAH

```bash
# 1. Migration
php artisan migrate

# 2. Clear cache
php artisan cache:clear && php artisan route:cache

# 3. Run
php artisan serve
```

**Then test at:** `http://localhost:8000/konsultasi`
